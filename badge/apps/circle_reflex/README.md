# Circle Reflex

Circle Reflex is a reflex game where you tap an arrow button as a spinning needle reaches each target.

## Usage

Open **Circle Reflex** from the badge menu and press any arrow button (Up,
Down, Left, or Right) when the needle touches the green target. A successful
hit reverses the needle, adds speed, and lowers the center count. Pressing too
early or letting the needle pass the target ends the run; the results show how
many targets you hit and how many remain. Each new target is random within the
next 180 degrees in the needle's current direction; the first target is at
least 90 degrees away to give you time to react. Press **Select** on the results
screen to try again. Clear all 50 targets to win. **Home** returns to the badge
menu.

No extra hardware, Wi-Fi, or secrets are required.
