# Traveling Creature

Raise a tiny pet that travels between GitHub Universe badges and remembers everyone it meets.

画面と説明はすべて日本語です。バッジには1匹だけ住めて、近くのバッジと自分のペットを交換します。

## Usage

1. タイトル画面で **SELECT** を押すと、4ページの説明が始まります。**SELECT** か **RIGHT** で次へ、**LEFT** で前へ進みます。2回目からは **SELECT** ですぐ始まり、**MENU** で説明をもう一度見られます。
2. 最初はたまごです。**SELECT** を押すと生まれます。
3. **LEFT** か **RIGHT** でなでると喜びます。
4. バッジを上下さかさまにすると、種類ごとに反応が変わります。モチは落ちて目を回し、フワは浮かび、コロは転がり、ペタはぶら下がります。
5. 同じアプリを開いた2台のバッジを近づけ、両方で **SELECT** を押すとペットを交換します。**BACK** で断ります。
6. **MENU** で旅日記を開き、**UP** と **DOWN** で歴代の主人を見ます。生みの親と、いまいるバッジには印が付きます。**BACK** で戻ります。
7. **HOME** でメニューに戻っても、ペットと日記は保存されます。

ペットは4種類います。

| ペット | 住む場所 |
| --- | --- |
| モチ | おうち |
| フワ | そうげん |
| コロ | さばく |
| ペタ | にわ |

旅をして多くの人に会うと、成長してアイテムが増えます。生みの親のバッジに戻ると「おかえり」の演出が出ます。前に会ったペットとまた会うと、別の演出が出ます。

## Requirements

Swapping uses the built-in Bluetooth badge link and needs two physical badges running this app. The simulator can check the screens, hatching, petting, flip reactions and diary, but not the swap.

## Assets

The images in `assets/` and `icon.png` are generated by `tools/build_traveling_creature_assets.py`. Regenerate them after changing any Japanese text in `__init__.py`:

```bash
python3 tools/build_traveling_creature_assets.py
```

The script downloads the k8x12 bitmap font by Num Kadoma ([littlelimit.net](https://littlelimit.net/k8x12.htm)), which is free to use, modify and redistribute. Pass `--font path/to/k8x12.bdf` to use a local copy.
