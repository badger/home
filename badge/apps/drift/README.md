# Drift

An ambient animation of glowing vector squares that float, tilt, and gently bump into each other around a GitHub Invertocat.

## Usage

Launch **Drift** and let it run. Tilt or nudge the badge and the squares swing with floating momentum before settling back into a slow drift; they collide softly and glow briefly when they touch. The Invertocat stays anchored in the centre as an immovable obstacle, so squares bounce off it and it flashes when hit. Press Select for a gentle outward burst. Uses the onboard accelerometer; no network or extra hardware is required.
