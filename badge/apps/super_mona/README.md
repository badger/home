# Super Mona

Run, jump and stomp through three side-scrolling stages as Mona in this original platformer for the Universe 2026 badge.

## How to play

Reach the flag at the end of each stage before the timer runs out. Collect
floating stars (100 stars earns an extra life), bump `?` blocks for power
chips, sparkles and 1-ups, and stomp bugs and shellbots. Kick a shellbot's
shell — or hold **B** to pick it up and release **B** to throw it.

## Controls

The capacitive pads follow a Game Boy-style layout.

| Pad | Action |
| --- | --- |
| D-pad | Move Mona (Down crouches when big) |
| Select (A) | Jump — hold for a higher jump |
| Back (B) | Run; hold to pick up a shell, release to throw it |
| Menu (Start) | Pause |
| Home | Quit to the menu |

The pause screen has four pages; use **Left/Right** to switch between them:

- **PAUSED**: score and high score.
- **MAP**: an overview of the stage showing where you are.
- **ITEMS**: power chips collected while already big are stored here (up to
  three). Use **Up/Down** and **A** to use one.
- **HERO**: swap between Mona and Luna with **A** on stages that allow it
  (1-2 and 1-3). Luna jumps higher but has less grip.

Press **Menu** or **B** to resume.

## Notes

- Runs in LORES (160x120) for a smooth frame rate; no network or extra
  hardware is needed.
- The high score is saved with `badgeware.State`.
- Tile and enemy art is generated by `tools/build_super_mona_assets.py`; the
  player sprites are derived from the Flappy Mona frames.
