# Jostle

An ambient animation of glowing vector squares that float, tilt, and gently bump into each other around a GitHub Invertocat.

## Usage

Launch **Jostle** and let it run. Tilt or nudge the badge and the squares swing with floating momentum before settling back into a slow drift; they collide softly and glow briefly when they touch. The Invertocat stays anchored in the centre as an immovable obstacle, so squares bounce off it and it flashes when hit. Press Select for a gentle outward burst.

Press Left or Right to launch the Invertocat to that edge. The jolt flings the squares to the opposite side, half of them fly off screen, and the rest lock into two columns linked to the Invertocat by animated flow lines in a dimmed version of each square's colour. A random few lines glow brighter, bright pulses occasionally race along them, and the background specks soften into out-of-focus bokeh. Press Select (or the opposite direction) to bring everything back to the ambient drift.

Uses the onboard accelerometer; no network or extra hardware is required.
