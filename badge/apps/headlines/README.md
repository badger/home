# Headlines

Headlines shows the latest US news headlines and summaries from NPR over Wi-Fi.

## Usage

Open **Headlines** from the badge menu.

- UP / DOWN: move between headlines (or scroll an open story).
- SELECT: open the highlighted story's summary; SELECT or BACK closes it.
- RIGHT: refresh now (it also refreshes every 10 minutes).
- HOME: return to the menu.

Requires Wi-Fi: set your network in Settings (`WIFI_SSID` / `WIFI_PASSWORD`).
Headlines and summaries come from NPR's public news RSS feed, which needs no key. Full articles are not loaded.
