# AutoGPT Bounce

A bouncing AutoGPT screensaver that swaps between the logo, AutoGPT Experts and other AutoGPT bits every time it hits an edge.

## Usage

Launch **Autogpt Bounce** from the menu. Like the Sparkle show's bouncing
Invertocat, the picture drifts diagonally across a navy screen while the case
lights pulse. Each bounce swaps it for the next item, cycling through:

1. the AutoGPT logo;
2. an AutoGPT Expert (Otto, Maria, Max, Frankie and eight more) with their role;
3. something else: the AutoGPT mark, "Your team of AI Experts", `agpt.co`,
   "Let Otto coordinate." or the project's GitHub stars.

The case lights flash on every bounce and blink when it hits a corner.

| Button | Action |
| --- | --- |
| Select | Swap to the next item now |
| Home | Return to the menu |

No Wi-Fi, `secrets.py` or extra hardware is needed.
